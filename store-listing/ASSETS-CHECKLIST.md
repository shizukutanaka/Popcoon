# Google Play 提出用ストア素材チェックリスト

`store-listing/{en-US,ja-JP,ko-KR,zh-CN}/listing.md` にタイトル・短い説明・詳細説明は
4ロケール分揃っている。**視覚素材 (画像) は本リポジトリに一切存在せず、
Play Console への提出をブロックする** (商用リリース監査で発見)。

この環境には Android SDK / エミュレータが無く実機・エミュレータのスクリーンショットを
撮影できないため、以下は人間が別途用意する必要がある。

## 必須 (揃っていないと審査に提出できない)

- [ ] **スクリーンショット (電話) 最低2枚、最大8枚**
  - フォーマット: JPEG または 24-bit PNG (アルファ無し)
  - 各辺 320px〜3840px、アスペクト比 16:9〜9:16
  - 推奨カット: 検索結果画面 (買い時スコア表示)、商品詳細画面 (ダークパターン警告)、
    ウォッチリスト画面、セールカレンダー画面 — アプリの差別化機能が一目で伝わるもの
  - 4ロケール分 (ja-JP/en-US/ko-KR/zh-CN) を推奨。日本語版のみ先行提出も可能だが、
    多言語ストア展開を謳う以上は揃えるのが望ましい
- [ ] **フィーチャーグラフィック 1024×500px** (JPEG または 24-bit PNG)
  - Play ストアのアプリページ上部に表示される横長バナー
- [ ] **アプリアイコン 512×512px** (32-bit PNG、アルファ可)
  - 現状 `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` に実アダプティブアイコン
    (単色 "P" パス、モノクローム/Android 13+ themed icon 対応済み) はあるが、
    これは端末上のランチャーアイコン用。Play Console 提出用の 512×512 hi-res icon は
    別途書き出しが必要 (アダプティブアイコンの前景+背景を合成してエクスポートする)

## 推奨 (無くても提出できるが訴求力に影響)

- [ ] タブレット向けスクリーンショット (7インチ・10インチ、任意)
- [ ] プロモーション動画 (YouTube URL、任意)
- [ ] ローカライズ済みスクリーンショット (テキストが翻訳された状態のキャプチャ)

## 確認済み・対応不要

- [x] タイトル・短い説明・詳細説明 (4ロケール、`store-listing/*/listing.md`)
- [x] プライバシーポリシー (`PRIVACY.md`、Play Console のプライバシーポリシー URL 欄に
      GitHub 上の当該ファイルへのリンクを設定する)
- [x] アダプティブアイコン (前景/背景/モノクローム) — 端末ランチャー表示用

## 参考: 実機/エミュレータが用意でき次第の手順

```bash
# デバッグビルドを実機/エミュレータにインストールし、各画面をキャプチャ
./gradlew installDebug
adb exec-out screencap -p > screenshot_search.png
# ... 検索結果・商品詳細・ウォッチリスト・セールカレンダーの4枚を撮影

# 512×512 hi-res icon はアダプティブアイコンの合成結果を Android Studio の
# Image Asset Studio (res/mipmap 右クリック → New > Image Asset) で書き出すのが確実
```
