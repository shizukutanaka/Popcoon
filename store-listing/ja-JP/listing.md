# タイトル (30文字以内)

Popcoon: 価格比較・買い時AI

# 短い説明 (80文字以内)

Amazon・楽天・Yahooを横断比較。買い時スコア、ダークパターン検出、AI助言で本当のお得を判定。

# 詳細説明 (4000文字以内)

【3 EC を 1 アプリで横断比較】
Amazon・楽天市場・Yahoo!ショッピングの価格を 1 タップで比較。
Keepa では Amazon しか見えない、HOW MUCH では履歴が浅い、そんな不満を解決。

【日本の EC で本当に得をするための 4 つの武器】

▶ 買い時スコア 0-100
6 つのシグナル (過去最安・トレンド・割引率・変動・履歴・罠検出) を統合。
スコア 70 以上で「買い時」、35 以下で「待ち」と直感的に判断。

▶ ダークパターン自動検出
景品表示法違反になりかねない「常設セール」「参考価格詐欺」「セール前値上げ」「端数価格 (980 円・1980 円)」を自動検出。
お買い得だと思った商品の実態を可視化。

▶ AI 買い物アドバイザー
Anthropic Claude AI が「今買うべきか」を 100 文字で助言。
専門家の判断をいつでもポケットに。

▶ 越境 EC 関税シミュレーター
日本税関ルール (16,666 円免税・カテゴリ別関税) を反映した着払い価格を即時計算。
海外通販の本当のコストが事前に分かる。

【他にもこんな機能】
✓ セット販売の実質単価判定 (「3 本セット ¥1,200」が本当に得か)
✓ TCO 計算 (インクジェット・ノート PC・冷蔵庫の 5 年総コスト)
✓ エコ倫理スコア (CO2 + 労働条件)
✓ 価格通知アラート (過去最安到達で通知)

【プライバシー優先】
✓ テレメトリゼロ — ユーザー行動を一切送信しない
✓ オプトイン制 — クラッシュレポートも AI も明示同意必須
✓ GDPR Article 17 準拠 — 設定からワンタップで全データ削除
✓ オープンソース (MIT) — コードは GitHub で公開

【こんな人におすすめ】
・複数の EC を比較するのに時間がかかる
・「セール」表示を信じたくない
・送料込みの本当の価格を知りたい
・海外通販の関税が分からず不安
・買い物の判断に迷う

【動作環境】
Android 8.0 以降 (API 26+)
