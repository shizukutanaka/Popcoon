# 简短说明 (80字以内)

# 详细说明 (4000字以内)

【一个应用，横跨3大电商平台】
Amazon、乐天市场、Yahoo!购物——同时搜索，价格一目了然。
解决 Keepa 只支持 Amazon 的局限，也填补其他比价工具历史数据不足的缺陷。

【4大功能，识别真正的划算】

▶ 购买时机评分 0-100
综合6大信号（历史最低价/趋势/折扣率/波动/历史/陷阱检测），70分以上"立即购买"，35分以下"等待"。

▶ 暗黑模式自动检测
常态促销 / 虚高原价 / 大促前涨价 / 尾数定价——自动识别，让您不再被营销策略迷惑。

▶ AI购物顾问
Anthropic Claude AI 用100字告诉您"现在该不该买"，专家级判断随时随地。

▶ 跨境购物关税模拟
按日本海关规则（16,666円免税+分类税率）自动计算到岸价格，提前知道真实成本。

【其他功能】
✓ 套装商品实际单价判断（3件装¥1,200到底值不值？）
✓ TCO计算（打印机/笔记本/冰箱的5年总拥有成本）
✓ 环保伦理评分（CO2 + 劳工条件）
✓ 价格变动提醒
✓ 积分模拟器（乐天SPU/Yahoo 5日优惠 等）

【隐私优先】
✓ 零遥测 — 不收集任何用户行为数据
✓ 全数据即时删除（GDPR第17条）
✓ 开源（MIT）— 代码公开在 GitHub
